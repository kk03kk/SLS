## 为什么优先这些事情

最危险的不是漏测某个数值，而是训练任务与原版完整任务在路径、资源、动作、终止或随机时序上不同。前段弱模型很少看见 Heart，短评估也掩盖不了这些后段缺口。因此先完成钥匙与 Act4 连接流程，复查高影响顺序机制，再以自然轨迹连接局部证据，比立即增加训练预算更有价值。

覆盖并不要求穷举所有组合后才允许任何实验；可以明确发布经过验证的有限范围。但在完整 A20H 训练前，应具备真实钥匙/双 Boss/Act4/Heart 的连续代表性证据，并列出尚未验证的可达分支。规则修复必须形成新环境身份，按现有契约进行 weights-only 初始化或合规迁移，重新评估；旧实验继续保留旧环境身份。

等待期的近期交付应是：版本绑定证据矩阵、可复现差分/恢复报告、确认缺陷和最小修复、独立 CPU 验收，以及下一训练实验的预注册协议。NUS 结果回来后用来选择起点与判定保留门槛，而非替代环境校验。不追加新的 NUS 训练作业。
