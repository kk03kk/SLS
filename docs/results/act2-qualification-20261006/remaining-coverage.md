# 本轮资格的边界

当前仍在执行验收。即使72次受控运行和8条production轨迹全部匹配，结论也只适用于清单中实际触发的分支；不能据此宣称整个Act2与原版等价。

尚未系统覆盖的内容包括：

- Book、Byrd、Parasite、Slavers、Snake Plant与所有牌、药水、遗物、Artifact、死亡/复活组合的交互。三个seed不是穷举。
- 三个Act2 Boss的全部动作历史、召唤后存活组合、阶段转换与构筑组合；每Boss两个场景只覆盖已指定义务。
- 未被八条正常轨迹触发的事件分支、商店组合、奖励组合、地图生成及遭遇随机分支。
- Discovery等受动画帧推进影响的分支。validation中使用独立stock实测输入的匹配只证明该条件下的规则与重放；不能给所有production计时分支发放资格。
- 未抽到的跨幕资源/遗物/状态组合、不同难度、不同角色，以及Act3/Heart。

八条自然轨迹用于发现流程的首个分歧，不用于估计胜率，不比较checkpoint优劣。128-seed扫描只用于按既定规则选择覆盖；最终保留集没有使用。

本轮规则修复后的训练，须绑定新NativeSource和明确的迁移契约。旧lambda=.98 pilot保留原始身份，不能把环境修复收益归因于lambda；后续算法实验需要修复后环境中的匹配control。

已知实质差异不能以“范围外”直接忽略。若本轮轨迹发现新的差异，保留原始证据，定位首个分歧，并决定修复及相邻回归；其后的连锁差异不重复计为独立根因。
