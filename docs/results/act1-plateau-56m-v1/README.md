## 对后续实验的影响

失败分层样本中，守护者平均入场生命 64.93、六火亡魂 70.62、史莱姆老大
69.15，提示瓶颈不能只用“低血入场”解释。成功样本携带的药水较多，但
这只是关联；牌组构成、药水种类、Boss 机制和决策质量仍可能有影响。

明确跳过卡牌奖励仅一次、结束回合仍有可出牌动作 153 次，值得后续查
具体局面。SKIP_REWARD 还可能直接离开奖励页，不能以一个显式跳过次数
断言模型几乎拿走所有奖励；结束回合有可出牌动作也不一定错误。

下一步按已准备方案比较现有进度奖励与通关奖励，每组新增约 2M 决策，
从同一 56M 权重起步。保留训练种子、模型和其余 PPO 设置，依次运行，
按完整幕开发确认种子的通关数与配对胜负变化筛选。短预算结果不明显
不能排除奖励方向需要更长适应；新的训练尚未由本地执行。
