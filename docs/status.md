## 首段 20M

配置为 `configs/train/ironclad_a20_act12_real_entry_20m_r1.toml`。从 90M 父 checkpoint 只迁移模型权重，重新初始化 Adam、环境、记忆及选模记录；不同来源的旧作业不获准精确恢复。

整段按新 episode 开始次数交替 50% 正常开局、50% 真实第二幕地图入口，不是按决策数或每个 rollout 各半。入口库含 1493 个独立正常开局到达状态，保留实际血量、牌组、金币、遗物、药水及钥匙，不额外注入资源、不筛选未来胜者。生成时检查 2048 个开发种子，全部到达入口均保留；修复规则后所有合法前缀在最终来源重放，入口 checkpoint 无变化。旧来源生成的到达/失败数量不是当前来源重新测得的胜率。

唯一选模成绩为正常开局第二幕通关数；第一幕到达率及分组结局用于诊断。保留 v5、既有 WIN 奖励与 PPO 配方，不加入高血量课程，不强制领取金币/遗物。累计目标 110,013,696，即父起点 90,013,696 后新增 20M；按完整更新执行，当前布局预计新增 20,004,864。

正式计划为 A100 40GB、64 workers / 16 shards、rollout 256、序列 64、minibatch 16。本地 8GB GPU 的正式批量出现显存不足，失败保留；成功诊断使用 8 workers / 2 shards、相同序列 64、minibatch 4，显存峰值约 3.29GB。不能把小批量结果当成正式批量通过；服务器 `--prepare` 必须重放完整入口库、验证正式批量更新和恢复，失败则停在准备阶段。

Slurm 每作业三天，训练自身 66 小时预算、提前 15 分钟通知。到时安全保存同一 run 的 latest；若为 INTERRUPTED，重新提交同一配置继续剩余累计目标。FAILED 必须检查失败记录，不盲目续提。不为跑满三天临时改动配方。准确启动命令维护在 [training.md](training.md#首段混合课程服务器启动)。
